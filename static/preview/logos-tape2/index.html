VHS rental label × ghost: 25 concepts

Round 4: Ali’s pick (T10’s crooked orange rental label with marker lettering) on an accurate, photo-registered VHS shell (187 × 103 × 25 mm; reel axes 92 mm apart). Each lockup is shown textured (matte grain, light scuffs, worn label) on cream and black, with the clean version and the 64 / 32 / 16 px icon. Design preview only, not in production.
