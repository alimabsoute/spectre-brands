# Spectre Brands

Sourced, illustrated post-mortems of dead and ghost brands: companies that died, or live on only as a name.
Working domain: spectrebrands.com (not attached yet).

The index, category pages and search are generated from the data, so the list of brands lives in one
place: `companies/`. Each brand is tagged **Dead** (nothing operates under the name) or **Ghost** (the
name is still in use by someone) with a one-line, sourced justification; see `/about/` on the site.

| Page | What it is |
|---|---|
| `/` | hero with a headstone for every brand, Dead vs Ghost, featured post-mortem, "On this day", filterable index by category |
| `/<slug>/` | one post-mortem: story, timeline, map, numbers, commercials and footage, old website, gallery, people, press, cause of death, what-if, afterlife, sources |
| `/category/<id>/` | intro and cards for one category |
| `/about/` | methodology, Dead vs Ghost definitions, data-honesty rules, trademarks and fair use |
| `/search.json`, `/sitemap.xml`, `/robots.txt` | search index for the command palette, and SEO files |

## How it works

Every post-mortem page is generated from data files by one shared renderer. Nobody edits HTML.

```
site.json                      site copy, categories, causes of death, About page text
companies/<slug>/company.json  name, tier + justification, category, cause, theme colors, card, hero, key numbers
companies/<slug>/sections/*.json  one file per section (story.json, timeline.json, videos.json, ...)
companies/<slug>/art/*.svg     original illustrations, inlined into the page
companies/<slug>/img/*         archived screenshots, logos, photos (AVIF + JPEG fallback)
companies/_template/           copy this to start a new company (folders starting with _ are skipped)
lib/registry.mjs               THE SCHEMA: section ids, core vs optional, nav groups, page order, tiers
lib/sections.mjs, blocks.mjs   section and block renderers
lib/infographics.mjs           build-time SVG/HTML infographics (arc, waffle, flow, multiples, scale, chain, compare, bars)
lib/media.mjs                  <picture> with fallbacks and intrinsic sizes; video facades
lib/layout.mjs                 <head> (SEO, OpenGraph, JSON-LD), masthead, search dialog, section nav, footer
lib/home.mjs, pages.mjs, cards.mjs  homepage, category and About pages, the brand card
lib/md.mjs                     the tiny text markup (**bold**, [link](url), [^n] footnotes)
assets/css/tokens.css          every design token (colors, type, spacing, radius, shadow, motion)
assets/css/*.css               base, modules, infographics, map, home; concatenated into one site.css
assets/js/runtime.js           the only script on every page; charts.js and map.js load on demand
assets/vendor, assets/fonts    self-hosted Chart.js, rough.js, d3-geo, topojson, US atlas, and fonts
static/                        favicon files, copied to the site root
og/                            OpenGraph images, one per brand (generated by scripts/og.mjs, committed)
data/nasdaq.json               FRED NASDAQCOM weekly closes, Jul 1998 – Dec 2001
build.mjs                      validates everything and writes dist/
scripts/                       dev server, checks, screenshots, Lighthouse, research helpers
```

Core sections are required on every page; optional modules (map, website, gallery, ...) appear only
when a company has the file, and the section menu lists only what the page contains.
Full field reference: **[SCHEMA.md](SCHEMA.md)**.

## Build, preview and check

Node 18+ . The build itself has no dependencies; the dev tools use Playwright, sharp and Lighthouse.

```sh
npm install                 # dev tools only (first time: npx playwright install chromium)
npm run build               # node build.mjs: validates data, writes dist/
npm run dev                 # http://localhost:8000 with live reload on every change
npm run check               # build + internal link/anchor check + Playwright smoke test at 375 and 1280
npm run check -- --external # also check every external link (slow)
npm run media               # verify every embedded video still exists and is embeddable
npm run sources             # check every cited source URL still resolves (slow)
npm run lighthouse          # Lighthouse (mobile) for every page; fails under 85/95/95/95
npm run shots               # screenshots of every page at 375/768/1280/1440 into docs/qa/
npm run og                  # regenerate OpenGraph images into og/
```

The build fails with a readable message for invalid JSON, unknown section ids or block kinds, missing
core sections, missing drawings or images, unknown tiers, categories or causes, a footnote that has no
entry in sources.json, fewer than two videos, and a money-flow chart whose parts do not sum.

## Deploy

Vercel project `spectre-brands` (live at https://spectre-brands.vercel.app), connected to this repo; every push to `main` deploys to production.
`vercel.json` sets `buildCommand: node build.mjs`, `outputDirectory: dist`, `trailingSlash: true`.

## Images, video and libraries

Raster images are stored as AVIF with a JPEG (or PNG) fallback of the same name; the build emits
`<picture>` with intrinsic sizes and lazy loading. Archived websites are shown as **screenshots** of
Internet Archive captures (no iframes), each linked to its Wayback URL. Drawings in `art/` are original
illustrations, not official assets.

Videos are never hosted here. Each one is a thumbnail and a play button; the player (YouTube through
youtube-nocookie.com, or the Internet Archive) is created only when the reader presses play.

Chart.js 4, rough.js 4, d3-geo 3, topojson-client 3, the us-atlas state shapes and the fonts (Source
Serif 4, Inter, Caveat, Varela Round) are self-hosted under `assets/` and loaded only where needed.

## Data honesty rules

1. Every figure links to a numbered source (`[^n]` → Sources section). SEC filings first, then contemporary press, then archives.
2. Numbers we calculate are labeled **derived**; estimates are labeled **estimate**; claims we could not confirm are labeled **unverified** or left out. Each page's Sources section ends with data notes listing them.
3. Cause-of-death weights and what-if scenarios are editorial judgment and are labeled as such.
4. Logos, ads, footage and screenshots appear in historical/editorial context with captions and attribution; trademarks belong to their owners. The footer of every page carries the disclaimer.
5. Every chart and infographic has a data table underneath it.

## Adding a company

Follow [docs/ADD_A_BRAND.md](docs/ADD_A_BRAND.md). Short version: `cp -r companies/_template companies/<slug>`,
fill in `company.json` and the core section files (story, timeline, numbers, videos, cause, whatif,
afterlife, sources), add optional modules, images and drawings, then `npm run check`.
