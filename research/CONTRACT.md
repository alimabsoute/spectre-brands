# v2 pilot data contract (shared by research, code and writing agents)

## company.json additions
- `kind`: chain | company | product | hardware | service
- `listed`: [{ "exchange", "ticker", "from", "to" }] (empty if never public)
- `factFile`: ordered array of { "key", "label"?, "value", "when"?, "asOf"?, "src": [footnote ids], "ledger": [ledger ids] }
  keys: was, founded, peak, end, buyer (bought the company), nameOwner (owns the name today), remains, cause (computed by build from `cause`; omit)
- `signature`: map | stock | scrolly | recreation | rivals | yeartable  (the visual that opens the second act)

## Footnotes
- Prose keeps `[^n]` markers in data. Rendering changes only (per-paragraph "Sources" control).
- New sources are APPENDED to `sections/sources.json` with new ids; new prose cites them as `[^n]`.
  Each new source id must be referenced by at least one verified ledger entry (`"fn": n`).

## New block types (inside any section's `blocks`, or as listed)
- `{ "type": "stock", "title", "ticker", "exchange", "unit": "USD", "series": [{ "q": "1999Q3", "hi": 30.1, "lo": 17.0, "ledger": "bb-020" }], "events": [{ "q", "label" }], "note", "src": [n] }`  gaps = missing quarters, never interpolated
- `{ "type": "rivalchart", "title", "metric", "unit", "series": [{ "name", "points": [{ "year", "value", "ledger"|"src" }] }], "note", "src": [n] }`
- `{ "type": "storemap", "title", "dates": ["2004","2010"], "states": { "TX": [612, 210], ... }, "unknown": [a, b], "totals": [a, b], "note", "src": [n], "ledger": [...] }` (tile-grid US map; totals must reconcile with states+unknown)
- `story.json`: optional `"variant": "scrolly"` + `"stage": { "metric", "unit", "points": [{ "year", "value", "src"|"ledger" }] }` (sticky chart that advances with chapters; user-started Play)
- `timeline.json`: optional `"animated": true`
- `afterlife.json`: optional `"now": [{ "type": "trademark|company|brand|site|store|people|revival", "title", "text", "asOf": "YYYY-MM-DD", "recheck": "90d|365d", "src": [n], "ledger": [...] }]` rendered as "Where are they now" cards
- `whatif.json`: optional `"featured": [indexes]` (default first two); others go into a disclosure. Method notes go into a disclosure.

## Site data
- `data/glossary.json`: [{ "id", "term", "aliases": [], "def" }]  defs are short, contain no figures or dates
- `data/entities.json`: [{ "id", "name", "type": "Organization|Brand|Person", "slug"? }]
- `data/edges.json`: [{ "from", "to", "type": "owned|acquired|licensed|executive|investor|supplier|rival", "years", "status": "verified", "evidence": [{ "slug", "fn" } | { "ledger" }] }]
- `data/recheck.json`: generated by `scripts/recheck.mjs` from every `asOf`

## Gate additions
- `node scripts/ledger-check.mjs` passes
- `node scripts/facts.mjs --additive`: existing numbers/markers/quotes may not change; new ones allowed only when they appear in a verified ledger entry's `value`/`quote` for that slug
